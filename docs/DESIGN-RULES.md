# 视觉约定

竖屏触摸游戏，矿洞灰蓝、木质棕、铜金与羊皮纸。保持既有角色，不大幅偏移色彩。标题与纸面一体化，外长内短纹饰，不重新加厚木牌。描述框细于外框，文字保留内边距。

标题、内容、说明与主操作分层，不无限缩字。矿物按品质分组、不限制两种，自动换行与滚动；品质文字居中，底部操作不遮住末项。

普通弹窗“点击任意区域关闭。”，按钮/输入/滚动/交易优先，拖动不算关闭。成功失败保留显式操作，不能跳过结算。无体力，矿铲预算不变。

检查空库存、低余额、长昵称、多矿物、最高阶、禁用、滚动末项、文字挤压与素材变形。长屏背景按既定 720×1680 策略适配。Loading 填充用裁切，不随进度压缩整张图片。
